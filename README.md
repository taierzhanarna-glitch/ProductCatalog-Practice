# Product Catalog — NORD practice

Razor, strongly typed view, Layout және Partial View тақырыптарына арналған оқу жобасы. `ProductCatalogPractice.sln` файлын Visual Studio 2022-де ашып іске қосыңыз.

## Дизайн

`NORD / OBJECTS`: ашық сұр фон, графит түстер, көгілдір акцент және ықшам өнім карточкалары.

## Мүмкіндіктер

- Өнімдерді көру, санат/атау бойынша сүзу және бағамен сұрыптау.
- `Create` формасы арқылы жаңа өнім қосу.
- Суретті HTTPS URL-мен енгізіп, алдын ала көру.
- Сервер жағында модель валидациясы және HTTPS URL тексеруі.
- `Details` бетінде өнім мәліметі мен суретін көрсету.
- Bootstrap негізіндегі ортақ Layout және қайта қолданылатын `_ProductCard` partial.

Өнімдер әзірше сервердің жадында сақталады; қолданба қайта іске қосылғанда бастапқы үлгі тізім қайта жүктеледі. Өзіңіз кеңейтуге болатын тапсырма: файлдан сурет жүктеу және оны қауіпсіз тексеру.
